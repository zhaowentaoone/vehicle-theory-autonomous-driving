# 算法　Pacejka 魔术公式（纯工况）

## 公式

$$
F = D\sin\big(C\arctan(B\kappa - E(B\kappa-\arctan(B\kappa)))\big)
$$

$\kappa$ 为 $\alpha$ 或 $\sigma$（弧度或无量纲滑移）。

## 伪代码

```
function F = pacejka(kappa, B, C, D, E):
    x = B * kappa
    F = D * sin(C * arctan(x - E * (x - arctan(x))))
    return F
```

刚度 $C_\alpha = BCD$（$\kappa$ 为弧度时）。

## 教学用默认参数（单轴量级）

侧偏：$B=10,\ C=1.3,\ D=8000,\ E=0.5$  
则 $BCD=10\times 1.3\times 8000=104000\,\mathrm{N/rad}$（略高于全书线性 $C_{\alpha}=80000$，用于展示弯头；案例里会再给一组匹配 80000 的参数）。

## 调参直觉

| 想要的变化 | 动哪个 |
|------------|--------|
| 路面更滑、峰值更低 | 降 $D$（或降 $\mu$） |
| 原点更硬 | 增 $B$ |
| 峰值后掉得更明显 | 增 $C$ 使之 $>1$ |
| 峰值附近更「平」 | 调 $E$ |

## 失效

联合滑移、凸轮角、瞬态松弛长度（relaxation length）本公式都没有。做 ESP 或 HIL 需完整 MF-Tyre 或刷子模型。
