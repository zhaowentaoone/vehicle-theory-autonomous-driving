# 车辆理论与自动驾驶控制入门

面向：**计算机科学本科 → 机械工程研一、车辆与控制几乎为零**。

学完后你应能：

1. 看懂车辆动力学论文里的自行车模型、二自由度模型和轮胎侧偏假设。
2. 自己实现纵向/横向跟踪（PID、Pure Pursuit、Stanley、LQR、MPC）和卡尔曼估计。
3. 搭出可运行的仿真小项目（ACC + 车道保持、弯道轨迹跟踪）。
4. 把车辆模型接到强化学习环境上，为后续 RL 控车做准备。

本课程**不是**计算机视觉课，也不是强化学习大部头。感知只讲控制需要的接口；RL 只铺 MDP、与最优控制的关系、以及环境骨架。

## 你应该怎么学

建议顺序：**按章号，不要跳**。运动学没搞清就去写 MPC，公式会变成符号游戏。

每章固定四件事：

1. 读 `01-课件.md`（推导跟一遍，用纸算一次关键公式）。
2. 做 `02-习题.md`，再对 `03-习题答案.md`（先自己做）。
3. 跑 `04-案例/` 里的 Python **和** MATLAB，对照预期现象。
4. 若有 `05-算法/`，把伪代码手写一遍再看实现。

计科背景的优势：离散化、状态机、复杂度、代码结构你已经熟。短板：连续系统、力与力矩、轮胎、坐标系。课件会从直觉讲到公式，不假设你上过理论力学专业课。

## 环境

### Python 3.10+

在课程根目录：

```bash
conda create -n autodrive python=3.11
conda activate autodrive
pip install -r requirements.txt
```

核心包：`numpy` `scipy` `matplotlib`。第 10 章 MPC 用 `casadi`；第 14 章用 `gymnasium`。

运行某章案例时，先进入该章 `04-案例/python/`，或从根目录用绝对/相对路径执行。需要公共参数时，脚本会把 `common/python` 加进 `sys.path`。

### MATLAB

- 以 `.m` 脚本为主，尽量只用 Base MATLAB。
- 第 06、09 章若已安装 Control System Toolbox，会更方便；没有也可以用本课程手写的离散化与 LQR 例程。
- 第 10 章 MPC 用 `quadprog` 手写最小例子，**不绑定**付费 MPC Toolbox。
- 运行前把 `common/matlab` 加到路径，或先 `run` 一次 `vehicle_params.m`。

各章 `04-案例/README.md` 写了：输入是什么、应出现什么图、怎样判断自己做对了。

## 教学用车辆

默认一组紧凑型轿车参数（质量 1500 kg、轴距 2.8 m 等），见 `common/` 与 [符号与约定.md](符号与约定.md)。跨章不要随便改，否则你无法对比「同一辆车」在不同控制器下的行为。
