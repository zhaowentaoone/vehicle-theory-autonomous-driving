# 第 14 章课件　强化学习预备

## 1. 本章你将获得什么

- 会把「车 + 路」写成 MDP：状态、动作、转移、奖励、折扣。
- 能说清 **MPC 每步优化模型** vs **RL 学习策略** 的差别与互补。
- 知道为何车辆控制论文爱用 PPO，而不是随便上 DQN。
- 亲手把第 02 章模型包成环境，用随机策略和 PID 打出回报基线。**本课不训练深度网络到收敛**——那是后续课题，但环境接口必须现在正确。

## 2. 和自动驾驶哪一层有关

可以替控制，也可以替规划，甚至端到端替感知到控制。入门只替**横向转角**，状态直接给 $e_y,e_\psi$，避免一上来就像素输入。

## 3. 直觉

MPC：手里有一张说明书（自行车模型），每步按说明书算最好的几步棋。  
RL：说明书不准或写不出代价时，让智能体在仿真里试，记住「什么样的状态该打多少方向」。

没有说明书的直觉（第 01–10 章），reward 会变成炼丹：车学会了「贴边抖着走」因为你忘了罚转角。所以本课要求 PID 基线必须先高过随机策略。

## 4. 符号表

$s$ 状态（此处不是间距），$a$ 动作，$\pi(a|s)$ 策略，$r$ 奖励，$\gamma$ 折扣，$V^\pi,Q^\pi$ 价值。与车辆滑移率 $\sigma$、转角勿混——环境代码里用 `obs, act`。

## 5. 推导

### 5.1 MDP

五元组 $(\mathcal S,\mathcal A,P,r,\gamma)$。车道保持最小设计：

- 观测 $o=[e_y,e_\psi,v]$（可再加 $\delta_{\mathrm{prev}}$）。
- 动作 $a=\delta$（连续，饱和 $\pm 35^\circ$）。或离散成 5 档方便 DQN 对比。
- 转移：第 02 章欧拉 + 参考路径几何。
- 终止： $|e_y|>2.5\,\mathrm{m}$ 或超时。
- 奖励（教学用，先求能跑）：

$$
r = -e_y^2 - 0.5 e_\psi^2 - 0.05\delta^2 + r_{\mathrm{alive}}
$$

掉出道路给大负值。$r_{\mathrm{alive}}$ 鼓励活着，但不要大到淹没误差。

### 5.2 与 MPC 对比

|  | MPC | RL |
|--|-----|----|
| 需要模型 | 显式，在线优化 | 可无模型（从交互学） |
| 约束 | 硬约束自然 | 需进 reward 或安全层 |
| 泛化 | 换车要改模型 | 换车要再采样 |
| 可解释 | 相对强 | 弱 |
| 计算 | 在线 QP | 在线一次前向，学习离线 |

工程上常见：**RL 出参考或补残差，MPC 做安全投影**。不要把 RL 理解成必须扔掉第 10 章。

### 5.3 为何 PPO 常见

车辆动作连续，$\delta$ 是实数。DQN 吃离散动作，转角离散化会抖。DDPG/TD3 连续但超参脆。PPO 策略梯度 + 裁剪，实现相对稳，论文基线好复现。细节放到你真正训练时再读 Schulman 2017。本课只要求：策略是 $\pi_\theta(a|s)$，用优势函数更新，且 **clip** 防止一步更新太大。

### 5.4 环境实现要点（比选算法更重要）

- `reset` 随机初始 $e_y\in[-0.5,0.5]$，否则策略只会一种起步。
- `dt` 与控制章一致（0.02–0.05 s）。
- 观测归一化：网络输入大约 $O(1)$。
- 固定随机种子才能对比随机 vs PID。
- **先评 PID，再谈 RL 是否 magically 更好。**

## 6. 实现要点

案例环境不强制安装稳定版 Gymnasium API 的全部包装；若已 `pip install gymnasium` 可再包一层。核心类 `LaneKeepEnv` 只有 `reset/step`。PID 用 $ \delta = -k_y e_y - k_\psi e_\psi $。随机策略 $\delta\sim\mathrm{Uniform}(-\delta_{\max},\delta_{\max})$。

MATLAB 案例：同一环境逻辑的脚本，比较随机与「P 控制」平均回报（无 Gym）。

## 7. 失效

Reward hacking：只给存活奖励，车在路上画龙。Sim-to-real：轮胎、延迟、噪声没进环境，实车必崩。没有安全层的 RL 控制不能直接上路。

## 8. 科研延伸

Sutton & Barto 第 3–13 章选读；Schulman *PPO* 2017；车辆：Kendall 2019 真实 RL 驾驶；Chen / Liang 等 mixed MPC-RL。小问题：把延迟 50 ms 加进环境，看 PID 与你以后训练的策略谁更抗。
