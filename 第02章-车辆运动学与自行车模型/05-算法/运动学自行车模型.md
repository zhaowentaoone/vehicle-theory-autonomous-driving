# 算法　运动学自行车模型（后轴）

## 连续模型

状态 $x=[X,Y,\psi]^\top$，输入 $u=[\delta,v]^\top$：

$$
\dot X=v\cos\psi,\quad
\dot Y=v\sin\psi,\quad
\dot\psi=\frac{v}{L}\tan\delta
$$

## 伪代码（前向欧拉）

```
function x_next = bicycle_euler(x, v, delta, dt, L):
    X, Y, psi = x
    delta = clip(delta, -delta_max, delta_max)
    X    = X + dt * v * cos(psi)
    Y    = Y + dt * v * sin(psi)
    psi  = wrap_to_pi(psi + dt * v / L * tan(delta))
    return [X, Y, psi]
```

## 精确圆弧一步（常 v, δ）

若 $|\delta|<\epsilon$，退化为直线：$X{+}{=}v\Delta t\cos\psi$ 等。  
否则 $R=L/\tan\delta$，$\Delta\psi=v\Delta t/R$：

$$
X^{+}=X+R\big(\sin(\psi+\Delta\psi)-\sin\psi\big)
$$

$$
Y^{+}=Y+R\big(-\cos(\psi+\Delta\psi)+\cos\psi\big)
$$

（$R$ 带符号：$\delta<0$ 则 $R<0$。）

## 复杂度与实时性

每步 $O(1)$。10 kHz 也毫无压力。瓶颈永远在控制器（MPC）或规划。

## 调参表

| 量 | 建议 | 说明 |
|----|------|------|
| $\Delta t$ | 0.01 s | 开环仿真；控制可 0.01–0.05 s |
| $\delta_{\max}$ | 35° | 乘用车前轮大致量级 |
| $L$ | 2.8 m | 必须用真实轴距，不要用车长 |

## 对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| 欧拉 | 实现简单，MPC 易线性化 | 大步长圆不闭合 |
| RK4 | 开环精度高 | 推导离散线性模型麻烦 |
| 精确圆弧 | 常输入下几何正确 | 变输入或加动力学后不适用 |

## 失效

见课件第 7 节：高速、大 $a_y$、低附着、需要侧偏动力学时不要用。
