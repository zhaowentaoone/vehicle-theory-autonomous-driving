# 第 01 章　坐标系、刚体与车辆结构

- **前置**：第 00 章；高中向量；会矩阵乘法。
- **建议学时**：6 小时（含习题与案例）。
- **学完能做什么**：在惯性系与车体系之间变换一个点的坐标和速度；说出平面车辆有哪些自由度；指出转向/驱动/制动在简化模型里各变成哪个符号。
- **和自动驾驶的关系**：定位输出的是惯性系位姿；控制器算的转角在车体系；规划轨迹两者都用。坐标系错了，后面所有误差定义都错。
