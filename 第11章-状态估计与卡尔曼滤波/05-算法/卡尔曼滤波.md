# 算法　线性卡尔曼滤波

## 伪代码

```
x, P = x0, P0
loop:
    x = A @ x + B @ u
    P = A @ P @ A.T + Q
    y = measure()
    S = C @ P @ C.T + R
    K = P @ C.T @ inv(S)
    x = x + K @ (y - C @ x)
    P = (I - K @ C) @ P
```

## 调参

| 矩阵 | 起点直觉 |
|------|----------|
| $Q_{vv}$ | 「我认为速度随机游走有多剧烈」 |
| $R$ | 传感器手册方差，再乘 1–10 做余量 |
| $P_0$ | 比你对初值的信心更悲观一些 |

## 对比

互补滤波：频域手工分频，实现更简单，无协方差。粒子滤波：非高斯多峰，计算贵。车辆定位入门：IMU+GNSS 用 EKF 足够写论文的基线。
