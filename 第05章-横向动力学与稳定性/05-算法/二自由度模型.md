# 算法　线性二自由度横向模型

## 状态方程

$x=[v_y,r]^\top$，$u=\delta$，矩阵见课件与 `common/python/lateral_2dof.py`。

## 伪代码

```
A, B = lateral_AB(vx, veh)
x = [0, 0]
for k in 0..N-1:
    x = x + dt * (A @ x + B * delta[k])
```

也可对 $A$ 做矩阵指数 `expm(A*dt)` 得到精确线性离散化，第 09 章 LQR 会用。

## 参数敏感

| 参数变大 | 主要影响 |
|----------|----------|
| $C_f$ | 前轴更「抓地」，不足转向减弱 |
| $C_r$ | 后轴更稳，不足转向增强 |
| $v_x$ | 阻尼变弱，响应变慢或振荡 |
| $I_z$ | 横摆加速变钝 |

## 与运动学对比

运动学无 $v_y$ 状态。二自由度在小 $\delta$ 阶跃后会有 $v_y$ 瞬态；稳态圆半径大于 $L/\tan\delta$（不足转向时）。
